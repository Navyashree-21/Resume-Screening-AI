# Resume Screening AI

## Overview

Resume Screening AI is a Multi-Agent AI application that evaluates resumes against job descriptions using LangGraph and Google Gemini.

---

## Features

✔ Resume Parsing

✔ Skill Analysis

✔ Education Analysis

✔ Experience Analysis

✔ Salary Prediction

✔ ATS Matching

✔ Resume Improvement Suggestions

✔ PDF Report Generation
